# Unity Shooting Game Practice

## 프로젝트 개요

유튜브 강의를 참고하여 Unity로 제작한 간단한 2D 슈팅게임 실습 프로젝트입니다.

Unity 기본 조작, 오브젝트 이동, 발사체 처리, 충돌 판정, 적 생성 등 게임 개발의 기본 흐름을 익히기 위해 진행했습니다.

## 프로젝트 정보

* 프로젝트명: Unity Shooting Game Practice
* 개발 엔진: Unity
* 작업 형태: 개인 실습
* 참고 자료: YouTube
* 보관 상태: Unity 프로젝트 원본은 용량 문제로 Google Drive에 보관

## 주요 학습 내용

* 플레이어 이동 처리
* 발사체 생성 및 이동
* 적 오브젝트 생성
* 충돌 판정
* 게임 진행 흐름 구성
* Unity 프로젝트 구조 이해
