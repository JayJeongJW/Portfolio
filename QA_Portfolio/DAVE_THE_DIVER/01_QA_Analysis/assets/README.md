# site/assets/

`01_assets/`에서 웹에 필요한 파일만 선별 복사한 폴더입니다. 원본은 수정하지 않고 `01_assets/`에 보존합니다.

## 사용 범위

- `brand/`: 공식 DAVE THE DIVER 및 MINTROCKET 로고
- `official/`: Hero, 자료 범위, 패턴, 시나리오 섹션에 사용한 공식 게임 이미지
- `evidence/`: TS-CAT-002/003/015/018/040의 현재 판정 프레임 13장

TS-CAT-003의 얼굴 포함 과거 보조 자료는 복사하거나 공개하지 않았습니다. 증거 이미지의 확대·캡션·주석은 HTML/CSS/JavaScript 레이어로 구현합니다. Evidence 12장은 픽셀을 바꾸지 않는 무손실 WebP로 압축했고, 투명 채널 보존 검증을 통과하지 못한 TS-CAT-040 1장은 PNG를 유지했습니다.
