# site/

GitHub Pages 등 정적 호스팅에서 실행할 수 있는 DAVE THE DIVER QA Research Portfolio 정적 사이트입니다.

## 구성

- `index.html`: 28개 화면의 전체 콘텐츠와 46개 시나리오 권위 목록
- `css/v2.css`: 화면 디자인, 반응형, 접근성 상태
- `css/print.css`: A4 인쇄/PDF용 스타일
- `js/script.js`: 모바일 내비게이션, PAT별 시나리오 그룹 상태 유지, 증거 라이트박스, 인쇄 보조 동작
- `assets/`: 원본 자산을 보존한 선별 복사본

별도 빌드 과정이나 외부 CDN 없이 정적 서버에서 `index.html`을 열어 사용할 수 있습니다.
