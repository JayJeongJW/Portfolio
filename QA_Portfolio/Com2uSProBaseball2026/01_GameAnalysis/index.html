Live 퍼즐 개요

컴투스는 2026 시즌 업데이트에서 Live 퍼즐을 신규 콘텐츠로 소개했습니다.
  • 공식 설명은 조건에 맞는 Live 선수를 등록해 보드를 완성하는 방식이라고 밝힙니다.
  • App Store 버전 기록은 12.0.0·12.0.1에서 Live 퍼즐 추가를 명시합니다.
  • 인게임에서 Live 퍼즐은 컴프야 포인트 메뉴 안에 있습니다.

판타지 포인트와 선수 강화 화면의 포인트는 서로 다른 재화입니다. 이 문서에서 '판타지 포인트'로 적지 않은 '포인트'는 해당 화면의 별도 재화를 가리킵니다.

Ⅰ. 분석 배경과 결론

분석 대상 선정 이유

같은 Live 카드가 여러 사용처에서 경쟁하기 때문에 분석 대상으로 정했습니다.
이유 1 — 같은 카드가 여러 사용처에서 경쟁한다
  • 라인업 또는 향후 육성 자산으로 남길 수 있습니다.
  • 선수 특훈 재료로 사용할 수 있습니다.
  • Live 퍼즐에 투입해 판타지 포인트로 바꿀 수 있습니다.
이유 2 — 퍼즐 보상은 고정돼도 카드의 다른 가치는 다르다
  • Daily 필수조건 완성 보상은 판타지 포인트 1,200입니다.
  • 보너스 조건을 만족하면 총 2,400입니다.
  • 특훈 재료 선택 화면의 카드 사례는 0.1%부터 16.6%까지 서로 다른 경험치를 보여줍니다.
이유 3 — 카드 사용이 다른 성장 선택으로 이어진다
카드 선택 → 퍼즐 완성 → 판타지 포인트 → 상점 상품 선택 → 기존 선수 성장 또는 카드 획득
분석 문제 정의

Live 카드는 라인업 유지, 특훈 재료, 퍼즐 소모라는 여러 사용처를 가집니다. 하지만 각 사용 가치를 판단하는 정보는 서로 다른 화면에 나뉘어 있으며, 퍼즐 완료 이후에도 우편 수령을 거쳐야 판타지 포인트가 반영됩니다. 본 분석에서는 카드 소모 전에 필요한 판단 정보와 완료 이후 자산 처리 흐름을 중심으로 구조와 QA 리스크를 확인합니다.

핵심 결론

Live 퍼즐의 핵심은 카드 사용처 선택입니다.

컴프야 Live 퍼즐은 보유한 Live 카드를 조건형 보드에 소모해 판타지 포인트로 바꾸는 콘텐츠입니다. 같은 카드는 라인업 자산으로 남기거나, 특훈 재료로 쓰거나, 퍼즐에 투입할 수 있습니다.

얻은 포인트는 성장·변경 아이템과 카드팩으로 다시 쓸 수 있습니다. 카드 소모는 다른 성장 경로와 이어집니다.

1
복수 사용처
한 장의 카드가 전력, 특훈, 퍼즐에서 서로 다른 역할을 가집니다.
2
고정 보상과 다른 기회비용
퍼즐 보상은 카드 등급에 비례하지 않지만, 특훈 경험치와 라인업 가치는 카드마다 다릅니다.
3
포인트 획득 뒤의 재선택
포인트를 바로 쓸지, 높은 가격의 상품까지 모을지 다시 정합니다.

필수조건과 보너스

기본 완성과 추가 보상 사이에서 카드와 스타 사용을 선택합니다.
필수조건
보드를 완성하기 위해 반드시 충족해야 하는 조건입니다. 행과 열의 조건을 동시에 만족하는 카드를 교차점에 배치해야 합니다. 확인된 조건 사례는 구단, 투·타 구분, 포지션, 등번호, 능력치 합계, 등급 등입니다.
보너스
추가 카드를 사용해 총 보상을 높일 수 있는 선택 조건입니다. Daily 기준 필수조건만 만족하면 1,200포인트, 보너스까지 만족하면 2,400포인트를 받습니다.
조건 재설정
10스타를 사용해 현재 조건을 변경하는 선택 기능입니다. 변경 결과는 실행 전에 알 수 없습니다.

가격대가 만드는 선택 구조

낮은 가격대 상품은 현재 포인트로 비교적 빠르게 구매할 수 있는 선택지이고, 높은 가격대 상품은 즉시 소비하지 않고 포인트를 누적하는 두 번째 선택을 만듭니다. 핵심은 퍼즐 보상이 판타지 포인트를 거쳐 상점에서 다시 성장 선택으로 이어지는 순환 구조입니다.

구조적 장점

보유 카드와 목표에 따라 참여 수준을 조절할 수 있습니다.
장점 1 — 필수조건만 충족해도 완료 가능

구조적 이유 — 필수조건과 보너스 조건이 분리돼 있어, 스타 없이 필수조건만 맞춰도 기본 보상을 받을 수 있습니다.

사례 — Daily는 필수조건만 완성해도 1,200포인트가 지급됩니다.
장점 2 — 보너스 조건으로 추가 보상을 선택 가능

구조적 이유 — 보너스는 선택 사항이라 더 가치 있는 카드를 쓸지 말지 직접 정할 수 있습니다.

사례 — 보너스까지 만족하면 Daily 보상이 2,400포인트로 늘어납니다.
장점 3 — 판타지 상점 상품이 다음 참여 목표를 제공

구조적 이유 — 완료 보상이 즉시 소비되지 않고 상점 상품 구매라는 다음 목표로 이어집니다.

사례 — 10,000포인트 만능카드는 확인된 상품 중 높은 가격대로, 포인트를 바로 사용할지 누적할지 판단하게 하는 사례입니다.

이 장점은 화면과 규칙 구조를 바탕으로 한 분석입니다. 실제 만족도·잔존율·매출 효과를 주장하지 않습니다.
