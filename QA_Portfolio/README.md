# Game QA Portfolio

게임 QA 직무 준비 과정에서 작성한 테스트케이스, BTS/Jira 형식 이슈 리포트, 게임 시스템 QA 분석 자료를 정리한 공간입니다.

본 자료는 특정 게임을 홍보하기 위한 목적이 아니라, 게임 기능을 QA 관점에서 확인하고 문서화하는 연습 과정으로 작성했습니다.

---

## 업로드 자료

  - 기대 결과 / 실제 결과 구분
  - Pass / Fail 기준 정리

## 작성 방향

테스트케이스와 이슈 리포트는 기능을 단순히 플레이한 기록이 아니라, 확인 조건과 결과를 나누어 정리하는 방식에 중점을 두었습니다.

아직 실무 경험 기반의 문서는 아니지만, 게임 QA 직무를 준비하며 테스트 범위, 기대 결과, 실제 결과, 재현 절차를 문서화하는 연습 자료로 작성했습니다.
