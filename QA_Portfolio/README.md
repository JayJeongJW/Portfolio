# ARC Raiders QA Portfolio

ARC Raiders를 대상으로 작성한 게임 QA 포트폴리오입니다.

본 포트폴리오는 게임을 단순히 소개하는 자료가 아니라, 레이드 플레이 루프를 기준으로 시스템 흐름을 분석하고 테스트케이스와 BTS/Jira 형식 이슈 리포트로 확장한 QA 산출물입니다.

---

## 작성 흐름

1. 시스템 분석서에서 ARC Raiders의 레이드 플레이 루프와 상태 변화 구조를 정리했습니다.
2. 테스트케이스에서 기능별 확인 조건, 테스트 단계, 기대 결과, 실제 결과를 작성했습니다.
3. BTS/Jira 이슈 리포트에서 이슈화 가능한 항목을 선별해 재현 절차, 실제 결과, 기대 결과, 영향도 기준으로 정리했습니다.

---

## 주요 분석 기준

- 장비 슬롯, 보관함 수량, 실제 진입 장비의 일치 기준
- 전리품의 임시 보유와 탈출 이후 보상 확정 구분
- 탈출/실패 결과와 보관함·퀘스트 진행도 반영 일치
- 실패/포기 조건별 손실 처리 기준
- 무기 모델, 상호작용 위치, 그래픽 표시 변화 등 품질 리스크
