# Show My Life

## 프로젝트 개요

`Show My Life`는 TeamSparta 에서 진행한 팀 프로젝트로 진행한 게임 제작 실습입니다.

**Show My Life** 는 한국 학창 시절을 테마로 한 **감정이 가미 된 성장 구조형 3D 플랫포머 게임**입니다.
유년기부터 성장 과정을 따라가며 플레이어가 삶의 장면을 경험하는 형태의 게임을 목표로 제작했습니다.
