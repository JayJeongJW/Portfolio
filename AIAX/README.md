# n8n 기업정보 수집 워크플로우

기업정보 수집에 활용한 n8n 워크플로우 JSON을 정리한 폴더입니다.

## 먼저 볼 파일

| 수집 대상 | 메인 워크플로우 | 서브 워크플로우 |
| --- | --- | --- |
| 서울시 계약마당 | [메인](./서울시%20계약마당%20메인%20워크플로우.json) | [서브](./서울시%20계약마당%20서브%20워크플로우.json) |
| 유페이퍼 | [메인](./유페이퍼%20메인%20워크플로우.json) | [서브](./유페이퍼%20서브%20워크플로우.json) |

## 처리 흐름

메인 워크플로우를 수동 실행하면 Code와 Loop Over Items 노드로 처리 대상을 준비·반복하고, 해당 서브 워크플로우를 호출합니다.
서브 워크플로우는 HTTP 요청과 HTML·Code 노드로 응답을 처리하며, Notion 데이터베이스 페이지 생성 노드를 포함합니다.

## 업무에서의 경험

스마트동스쿨 AX 인턴 당시 기업정보 수집이 반복해서 중단됐습니다.
메인·서브로 작업 흐름을 나눈 뒤에도 중단 현상이 남아, 기존 데이터를 보존하면서 중단 지점부터 재개하는 방법을 적용했습니다.
약 34만 건의 정보를 전달하고 작업 흐름과 실행 방법을 문서화했습니다.

- [업무 정리 문서](https://jaewoo-qa-pr.vercel.app/documents/smartdongschool-n8n-workflow.pdf)

위 내용은 업무 수행 경험입니다. 이 폴더의 JSON만으로 전체 수집 결과나 최종 재개 동작까지 검증할 수 있다는 뜻은 아닙니다.

## 실행 전 확인할 사항

1. n8n에 메인과 서브 JSON을 각각 가져옵니다.
2. 메인의 Execute Workflow 노드에서 가져온 서브 워크플로우를 다시 선택합니다.
3. Notion 연결 자격 증명과 대상 데이터베이스, 수집 대상·범위를 실행 환경에 맞게 확인합니다.
4. 작은 범위로 실행해 출력과 저장 결과를 확인한 뒤 범위를 늘립니다.

JSON을 가져오는 것만으로 같은 결과가 보장되지는 않습니다. 외부 사이트의 변경과 실행 환경에 따라 조정이 필요할 수 있습니다.

## 기타 실습 파일

`test*.json` 등은 별도 실습 파일입니다. 전체 역할이 정리되지 않은 파일을 대표 실행 순서에 포함하지 않았습니다.
