# 🎮 정재우 Game QA Portfolio

안녕하세요.  
게임 QA 직무를 준비 중인 정재우입니다.

중학교 시절부터 프로게이머를 목표로 게임을 깊게 플레이했고, 이후 프로게임단 생활을 경험했습니다.  
현재는 그동안의 게임 플레이 경험을 바탕으로, 게임을 단순히 플레이하는 것에서 나아가 **QA 관점으로 분석하고 문서화하는 훈련**을 하고 있습니다.

이 저장소는 게임 QA 취업 준비 과정에서 작성한 포트폴리오, 테스트케이스, 이슈 리포트, 실습 자료를 정리한 공간입니다.

## Game Project

### [Show My Life](./GameProject_ShowMyLife)

TeamSparta에서 진행한 팀 프로젝트 기반 게임 제작 실습입니다.  
한국 학창 시절을 테마로 한 성장 구조형 3D 플랫포머 게임을 목표로 제작했습니다.

### [Unity Shooting Game Practice](./GameProject_UnityShooting)

Unity 기초 학습을 위해 제작한 2D 슈팅게임 실습 프로젝트입니다.  
플레이어 이동, 발사체 처리, 적 생성, 충돌 판정 등 게임 기능의 기본 구조를 학습했습니다.
