# 붉은사막 QA 포트폴리오

붉은사막의 클리프 플레이 구간을 중심으로 전투 기술 성장 구조를 분석하고,<br>
분석 결과를 테스트케이스와 Jira 형식의 버그리포트로 연결했습니다.

## 포트폴리오 구성

1. [전투 기술 성장 구조 분석서](./01_정재우_붉은사막_전투기술성장구조_분석서.pdf)
2. [QA 테스트케이스](./02_정재우_붉은사막_QA_테스트케이스.xlsx)
3. [Jira 버그리포트](./03_정재우_붉은사막_Jira_버그리포트.pdf)

## 주요 검증 범위

- 전투 기술의 습득·강화 단계와 입력 결과
- 기력·용기 등 전투 자원 부족 상태의 입력 처리
- 자동 대상 보정, 사거리, 방어 반응
- 해상도 변경과 화면 전환 후 UI·입력 복귀
- 저장 슬롯 표시 정보와 실제 로드 후 진행 상태의 정합성

## 판정 기준

확인 가능한 결과는 `Pass` 또는 `Fail`로 판정하고,<br>
기획 기준이 필요한 항목은 `Needs Spec`, 장비나 환경 제약으로 수행하지 못한 항목은 `Not Run`으로 구분했습니다.

## 테스트 환경

- Platform: PC / Steam
- Input: Keyboard / Mouse
- OS: Windows 11 Home 25H2
- Game Version: 1.12.02 / 1.15.00

직접 플레이 결과와 인게임에서 확인 가능한 설명을 기준으로 작성했으며,<br>
확정하기 어려운 범위는 추가 검증 또는 기획 확인 대상으로 분리했습니다.
